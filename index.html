Fingerprint Device Sync Platform
Remote fingerprint-template transfer across every branch, from one dashboard.
Every new hire needed a physical enrollment visit to their branch's fingerprint device. I built a Flask-based platform that manages all ZKTeco devices from one dashboard and transfers fingerprint templates between them remotely — eliminating on-site enrollment visits company-wide.

IT Assets & Ticketing Tracker
Central system for hardware, licenses, and support tickets.
IT requests came in through scattered emails with no history tied to the asset or user. I developed a tracker with automatic email-to-ticket classification, Active Directory sync, and Snipe-IT integration — centralizing every request and asset record in one place.

DVR/NVR Time Sync Tool
One-click clock sync across every surveillance recorder.
Each DVR/NVR's clock had to be corrected manually, one device at a time. I built a tool that talks to the Hikvision ISAPI to test connectivity and sync every device's clock in a single action — replacing per-device manual configuration.
PythonHikvision ISAPIREST
Hardware Health & Inventory Automation
Domain-wide disk and RAM health scan.
Deciding which machines needed a new drive or more RAM relied on guesswork. I wrote a PowerShell script that remotely scans every domain-joined machine for disk health (SMART + failure prediction), RAM specs, and full AD inventory — giving the team data instead of guesswork.
